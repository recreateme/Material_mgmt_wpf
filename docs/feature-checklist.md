# 功能对照检查表（WPF v4.4.0）

对照源项目 PyQt6 v3.0，并纳入 v4.2 / ui phase 增量。勾选表示已在 WPF 侧落地可演示。

快速上手：[quickstart.md](quickstart.md) · WPF 教程：[wpf-tutorial.md](wpf-tutorial.md)

## 壳与认证

- [x] 登录（仅用户名+密码，无身份单选）
- [x] 两角色：`system_admin` / `business`；旧 `admin`/`operator`/`root` 启动时迁移
- [x] 首次登录向导（`FirstLoginWizard`）：出厂默认密码须先改密，占位显示名可补填真实姓名（可跳过），一个窗口两步完成
- [x] 密码规则 `PasswordPolicy`：至少 6 位、不等于用户名、不能用出厂默认密码；改密、新增账号、重置密码共用
- [x] 登录卡片：显示/隐藏密码、大写锁定提示、记住上次用户名（不存密码）、用户名框 Enter 跳到密码框、Enter 登录
- [x] 失败 5 次锁定 60 秒；锁定期间倒计时每秒刷新，到时自动恢复
- [x] 登录背景图随包离线（`Assets/login-bg.jpg`，等比完整缩放不裁切，卡片在右侧独立区域）；在线图需 `[app] login_bg_online = true`
- [x] 主窗口左侧导航 + 角色过滤
- [x] 登录后重建面板缓存
- [x] 修改密码 / 退出登录（退出时关闭称量窗）
- [x] 窗口几何记忆（settings.ini）
- [x] 状态栏设备指示
- [x] 登录后按配置自动连接电子秤（可关；已配置口不盲目扫全 COM）
