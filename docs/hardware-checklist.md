**天平协议备注（对照实现）：**  
读重命令 `01 03 00 00 00 04 44 09`；置零 `01 06 00 04 00 01 09 CB`；CRC16 Modbus。若现场天平协议不同，需单独改 `ScaleWorker`。

## 快速排障

| 现象 | 优先排查 |
|------|----------|
| 无 COM 口 | 驱动、线缆、换 USB 口、设备管理器 |
| 已连接无读数 | 波特率是否 9600、协议是否匹配、线序 TX/RX |
| 扫码无反应 | 是否 HID 模式、焦点是否在本程序、码长是否 ≥4 |
| 扫码重复字符 | 少见；确认未安装其它全局键盘钩子 |
| 确认按钮灰 | 未稳定或超范围；先看引导文案 |
| 迁库后空数据 | 路径是否为 exe 同级 `data\` |
