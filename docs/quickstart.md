# Quickstart：原料管理系统

本文帮助你在 5～10 分钟内跑起来，并走通一条「业务人员称量」主路径（WPF v4.2）。

## 1. 你需要什么

- Windows 10/11
- 二选一：
  - **A. 已打包程序**（无需安装 .NET）
  - **B. 源码 + .NET 8 SDK**（开发调试）

电子秤 / 扫码枪为可选项；无硬件时仍可登录、维护主数据，设置页可「模拟扫码」。

## 2. 方式 A：运行打包版

1. 打开目录：`dist\原料管理系统`（仓库根目录下）
2. 双击 `原料管理系统.exe`
3. 输入用户名与密码登录（**无需再选身份**；权限由账号角色决定）
4. 试用账号（空库或种子库）：

| 角色 | 用户名 | 密码 | 可做 |
|------|--------|------|------|
| 系统管理员 | `admin` | `88888888` | 业务人员账号、系统设置 |
| 业务人员 | `operator` | `operator123` | 原料/配方/称量/工单、系统设置 |

生产库迁移后：原 `admin`→系统管理员；原操作员账号→业务人员；`root` 已删除。

登录后状态栏会尝试 **自动识别并连接电子秤**。若未插天平，会提示「未识别到…」并后台重试，不影响其它功能。

## 3. 方式 B：源码运行

```powershell
cd src
dotnet restore
dotnet run --project MaterialMgmt.App
```

首次运行请复制配置模板：

```powershell
copy config\settings.example.ini config\settings.ini
```

开发时数据库默认在仓库根目录：`data\material_mgmt.db`（通过 `WPF重构计划.md` 定位根路径）。

## 4. 业务人员主路径（称量）

前提：库中已有 **启用配方** 且配方下有步骤；步骤关联的原材料编码可被扫码枪扫到。

1. 以 **业务人员** 登录（主窗可改原料/配方；称量在独立窗）  
2. 侧栏点 **打开称量窗**（或首页「打开称量窗」）  
3. 在称量窗 **开始称量** → 选择配方（或扫 `FML-` 配方码）  
4. 填写工艺参数（温度、湿度、生产编号、基膜等）→ 开始  
5. 左侧 **称量进度**：绿色=已完成（可点回称）、灰色=待称；当前步高亮  
6. 扫码正确后：左上角显示 **绿色 ✓ + 材料名**，中央实时显示克重（称量中扫码只进称量窗）  
7. 未稳定时显示「稳定中」；稳定且在范围内后点 **确认称重** 或按 **空格** 进入下一材料  
8. 可点击已完成步骤重新称量（作废该步记录，后面已完成步保留）；不可点未完成的未来步  
9. 全部步骤完成后工单结束；可在称量窗 **我的工单** 导出 / 取消 / 删除已完成或已取消  
10. 关称量窗不会退出登录；主窗「退出登录」会同时关闭称量窗

## 5. 业务人员常用路径（主数据）

1. **原材料**：新增（可手工指定条码）、删除（勾选 + 全选）  
2. **配方管理**：新建 / **复制配方** → **编辑步骤**（材料上下限须 > 0，可扫码选料；调整顺序后点「保存顺序」或「完成」）→ 启用（可多选）  
3. **工单历史**：查看详情 / 异常说明、导出；仅可删除已完成或已取消（进行中请先取消）  

## 5b. 系统管理员常用路径

1. **用户管理**：创建/停用业务人员账号、重置密码（密码至少 6 位）  
2. **系统设置**：串口、扫码、改密  

表格均支持行复选框与「全选 / 取消全选」（作用于当前页）。

## 6. 系统设置（可选）

- **电子天平**：一般登录后自动连接；也可手动选 COM 口 → 保存并连接  
- **扫码枪**：推荐 **USB COM**；选扫码 COM、模式「自动」或「仅串口」→ 保存；可「硬件自检」与「模拟扫码」  
- **修改密码**

配置文件：`config\settings.ini`（模板见 `config\settings.example.ini`）。

## 7. 重新打包（保留现有库）

在仓库根目录：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\publish.ps1
```

会备份并写回 `dist\原料管理系统\data\material_mgmt.db` 与 `config\settings.ini`。

## 8. 出问题先看哪里

| 现象 | 处理 |
|------|------|
| 登录后窗口立刻退出 | 看 `logs\app.log` |
| 电子秤未连接 | 插线、确认驱动、看状态栏；设置页刷新端口 |
| 扫码无反应 | 确认已保存扫码 COM；关闭串口助手避免占口 |
| 扫码缺字 | 枪改为 USB COM，勿用键盘楔入模式 |
| 手工编码保存失败 | 检查编码是否重复；长度 1～64，勿含空格 |
| 添加步骤看不到保存 / 保存失败 | 请用 v4.2+；上下限须 > 0；调整顺序后点「保存顺序」或「完成」 |
| 系统管理员看不到原料/配方 | 正常：主数据仅业务人员可进；称量请用业务人员账号开称量窗 |
| 删除工单失败 | 进行中工单须先取消再删 |
| 数据丢失 | 确认打开的是含 `data\` 的完整文件夹，不要只拷 exe |
