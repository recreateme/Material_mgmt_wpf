# 原料管理系统使用说明书（v4.4.0）

这份说明书只讲界面上怎么操作。改代码、接新设备、看调用关系，请读 [技术说明书.md](技术说明书.md)。端口、波特率和联调签字项见 [TECH.md](TECH.md) 第一章与 [hardware-checklist.md](hardware-checklist.md)。

程序是装在称量电脑上的单机软件。原料、配方、工单和称重记录都在本机数据库里，不依赖网络。

## 1. 两种账号看到的菜单不同

登录只输入用户名和密码，不用选择身份。系统按账号角色打开对应菜单。

| 位置 | 业务人员 | 系统管理员 |
|------|----------|------------|
| 主窗口 · 日常 | 首页、开始称量、我的工单 | 首页 |
| 主窗口 · 管理 | 原材料、配方管理、工单历史、系统设置 | 用户管理、系统设置 |
| 称量窗口 | 开始称量、我的工单 | 没有称量窗口 |

「开始称量」和「我的工单」会打开单独的称量窗口，同时只能有一个。主窗口继续留着，用来管原料、配方和全部工单。

左下角始终有「修改密码」和「退出登录」。退出登录会先关掉称量窗口，并断开电子秤。

## 2. 登录

- 用户名框按 Enter 跳到密码框，密码框按 Enter 登录。
- 可以显示或隐藏密码。键盘开着大写锁定时会提示。
- 「记住用户名」只记住用户名，不记住密码。
- 连续输错 5 次，该账号锁定 60 秒。倒计时每秒刷新，到时自动恢复，不用重启程序。
- 第一次用出厂密码登录时，会先要求改密码，然后可以填写真实姓名。姓名可以跳过。
- 新密码至少 6 位，不能和用户名相同，也不能再用出厂默认密码。新增账号、重置密码用同一套规则。已经在用的旧密码不会被强制改掉，除非本人去改，或管理员重置。

空库第一次启动才会写入两个种子账号（管理员 `admin`、业务人员 `operator`）。初始密码写在随发布包的交付单里，不写在本说明书中。现场从旧库升级时不会重置已有密码。

## 3. 窗口上常看的两处

**底部状态栏**（主窗口和称量窗口相同）：电子秤、扫码枪是否连上。异常时整条变成警示底色，点击对应设备会重连。扫码枪空闲时，状态栏会提示当前是串口还是键盘模式。

**右上角提示条**：保存成功、请先选择一行，这类提示出现几秒后自己消失，不挡住操作。导出成功的提示条上有「打开所在文件夹」。警告和错误用对话框，按 Esc 关闭。删除、作废这类操作会先弹出确认框。

列表页的共同操作：

- 表头复选框选中当前页；已经选了一部分时显示横杠。
- 底部分页：每页 10 / 20 / 50 条，每个页面各自记住。可以输入页码跳转。
- 没有数据时，页面中间给出说明和主操作按钮。筛选后没有结果时，可以一键清除筛选。

## 4. 业务人员：完成一张工单

### 4.1 首页

- 「开始称量」大按钮，进入称量窗口。
- 全部进行中的工单：本人的可以点「继续」；别人的只显示，不能接着称。
- 三个今日数字：今日开工的工单数、今日完成数、今日含重称的工单数。含重称指这张工单里有被作废后重称的记录，用来看现场返工，不是超范围次数。超范围的读数不会存成有效记录。

### 4.2 开始称量

1. 若本人有未完成工单，页顶会列出，可直接继续，不必新建。
2. 选择配方，或在本页扫配方码（`FML-` 开头）。
3. 下方表格是步骤预览：顺序、原料、目标克重范围。没有步骤的配方不能开工。
4. 确认后填写工艺参数：温度、湿度、生产编号、D50、基膜、批号、厚度，以及混料 / 涂布是否异常和说明。
5. 确定后生成一张「进行中」工单，并进入称量页。

### 4.3 称量中

左侧是步骤进度：灰色是还没称，当前步高亮，绿色是已完成。已完成的步可以点回去重称；还没轮到的步不能点。

每一步：

1. 扫描当前原料的条码。条码必须和原料编码一致（推荐 `MAT-` 开头，比对时忽略大小写和首尾空格）。扫错会提示应扫什么、实扫什么，停留在等待扫码。
2. 把原料放到秤上。读数不稳定时显示「稳定中」，确认按钮不可用。
3. 读数稳定且落在配方上下限内，点「确认」或按空格。这一步写入一条有效称重记录，自动进入下一步。
4. 稳定但超出范围时，提示高了或低了多少克，调整用量，等再次稳定。这个读数不会存成有效记录。
5. 称重过程中再扫一次，会回到「等待扫码」，用来纠正放错的料。
6. 电子秤断线或读数长时间不更新时，已经亮起的「可以确认」会被取消，避免对过期克重点确认。

全部步骤完成后，工单变为「已完成」。

**回称（重称某一步）**：点左侧已完成的步骤，选择作废原因：读数异常、放错料、加料量需调整，或「其他」并填写说明。该步原来的有效记录改为作废，保留作废人、时间和原因，然后重新扫码称重。后面已经称完且仍然有效的步骤会自动跳过，不用从头再称。

**取消工单**：进行中的工单可以取消，状态变为「已取消」。已取消和已完成的工单才能删除；进行中的必须先取消。

称量进行中，扫码只进入称量窗口，不会跑去改别的页面上的输入框。称量页不接受「模拟扫码」。

设置里打开提示音后，合格、超范围、扫错、读数中断会有声音。音量分低、中、高，可在系统设置里试听。

### 4.4 我的工单

只看本人的工单。可以按状态、开始日期、配方和关键字筛选。

- 进行中：继续称量，或取消。
- 已完成、已取消：可以删除，可以导出 Excel。
- 导出只包含有效称重记录。成功后右上角提示文件名，可打开文件所在文件夹。若文件正被 Excel 打开，导出会说明失败原因。

## 5. 原材料

业务人员在主窗口「原材料」中维护。

- 新增时填写名称、描述。编码留空则自动生成 `MAT-` 编号，也可以手工指定。编码重复或格式不对时，错误显示在输入框旁边。
- 搜索框可按编码或名称过滤，也可以把扫码枪对准搜索框扫原料码。
- 勾选后可批量删除。已经被某个配方步骤使用的原料不能删除，程序会说明原因。

标签上的字符串必须等于这里的编码。像 `WH-814(20260303)` 这种外部批号，程序不会自动换成 `MAT-` 编码，称量时会一直报「原料错误」。需要把标签改成系统编码，或保证原料主数据里的编码就是标签上的那串字符。

## 6. 配方

### 6.1 列表

- 新建配方：填写名称，编码可自动生成 `FML-`。
- 复制：按一份现有配方生成新配方，步骤一起复制，之后可以单独改。
- 多选后启用或停用。停用的配方不应再用于新工单。
- 删除：已经有工单引用的配方不能删除。

### 6.2 编辑步骤

打开某份配方的步骤页：

- 新增步骤：选择原料，填写克重下限和上限。下限必须大于 0，且不能大于上限，输入时会即时提示。
- 「保存并继续添加」保存当前步并留在弹窗里，方便连续录入。下一次插入位置会自动往后移。
- 调整顺序：按住行首 ⋮⋮ 拖动，松手即保存；也可以用上移、下移。
- 有称重记录的步骤不能删除，避免历史工单对不上步骤。
- 这份配方只要还有「进行中」的工单，步骤页会锁住，并写明是哪几张工单。完成或取消那些工单之后才能改步骤。

## 7. 工单历史

业务人员查看全部工单，不限于本人。筛选条件与「我的工单」相同：状态、开始日期区间、配方、关键字（配方、生产编号、操作员）。

选中一行后：

- **详情 / 异常说明**：配方、操作员、生产编号、温度湿度等参数；称重记录表包含有效和作废记录，作废行能看到原因和扫码来源（串口扫码枪、键盘模式扫码枪、模拟输入；旧数据这一列为空）。
- 勾选「混料异常」或「涂布异常」并填写说明，点「保存异常说明」。说明前后的空格会被去掉。
- **导出 / 批量导出**：每个工单一个工作表，只导出有效记录。原料名称和上下限优先用称重当时的快照；很老的记录没有快照时，才用配方当前值。
- **删除**：进行中的工单按钮不可用。删除是从列表中移除，称重记录仍留在库里，供追溯。

## 8. 系统管理员

系统管理员不维护原料和配方，也不称量。日常工作是账号和数据安全。

### 8.1 用户管理

只管理业务人员账号：新建、修改显示名、重置密码、禁用、删除。

- 新建和重置密码使用第 2 节的密码规则。
- 禁用后该账号不能登录，工单仍挂在原人名下。
- 删除一个已经有工单的账号时，可以选择「仅禁用」，或「解除工单关联后删除」。解除关联后，那些工单还在，只是不再指向这个账号。

### 8.2 首页「数据安全」

- 最近一次备份的时间。
- 「立即备份」：把当前数据库复制到 `data/backup/`。程序在启动和正常退出时也会各留一份，备份目录最多保留 14 份。
- 「修复重复有效记录」：同一工单同一步骤若出现多条有效记录，只保留一条，其余标为作废，原因是「系统修复」。正常确认称重不会产生这种情况。

## 9. 系统设置（两种角色都可以）

电子秤和扫码枪必须使用不同的 COM 口，保存时如果填成同一个口，程序会拒绝。

| 设置 | 作用 |
|------|------|
| 电子秤端口、波特率 | 默认 9600。可自动连接 |
| 扫码枪端口、波特率、模式 | 见下表 |
| 硬件自检 | 检查当前配置能否打开设备 |
| 提示音开关、音量、试听 | 低 / 中 / 高 |
| 模拟扫码 | 仅系统管理员可见，用于没有枪时的联调。称量页会拒绝这种码 |

扫码模式：

| 模式 | 什么时候用 |
|------|------------|
| 自动 | 填了扫码 COM 就用串口；没填则用键盘模式 |
| 仅串口 | 只用 USB 虚拟串口。打不开就报错，不会偷偷改用键盘 |
| 仅 HID | 扫码枪当成键盘。复杂条码可能丢字，只在串口暂时不可用时用 |

推荐把扫码枪设成 USB 虚拟串口、9600、后缀回车，然后在这里选「自动」或「仅串口」并保存。键盘模式（USB KBW）在现场出现过丢字符。

改完端口后看底部状态栏。秤或扫码枪异常时，点击状态栏上的那一项即可重连。

## 10. 操作时常见现象

| 看到的现象 | 含义和处理 |
|------------|------------|
| 确认按钮是灰的 | 还没扫对原料，或读数未稳定，或不在上下限内 |
| 「原料错误」 | 条码和当前步骤的原料编码不一致。核对标签，或在称重中重扫正确的码 |
| 扫码完全没反应 | 看状态栏。确认扫码 COM 已保存，且没有被串口调试工具占用 |
| 扫出来少了字符 | 把枪从键盘模式改成 USB 串口 |
| 删除原料或配方失败 | 原料已被配方使用，或配方已有工单 |
| 配方步骤不能改 | 还有进行中的工单引用它，页上会写出工单号 |
| 进行中的工单不能删 | 先取消，再删除 |
| 导出失败 | 目标文件可能正被 Excel 打开，关掉后重试 |
| 管理员找不到原料菜单 | 正常。原料、配方、称量只属于业务人员 |
